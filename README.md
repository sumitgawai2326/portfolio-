## 🚀 Live Deployment on GitHub Pages

### 1-Click Upload (Windows Batch File):
Simply double-click [`push_to_github.bat`](./push_to_github.bat) located in this directory. It will automatically commit and push all files to `https://github.com/sumitgawai2326/portfolio-.git`.

### Manual CLI Commands:
```bash
git remote add origin https://github.com/sumitgawai2326/portfolio-.git
git branch -M main
git add .
git commit -m "feat: complete placement portfolio website for Sumit Rajendra Gawai (Class of 2029)"
git push -u origin main
```

### Enable GitHub Pages (Instant Live Link):
1. Open [https://github.com/sumitgawai2326/portfolio-/settings/pages](https://github.com/sumitgawai2326/portfolio-/settings/pages).
2. Under **Build and deployment > Source**, choose **Deploy from a branch**.
3. Under **Branch**, select **`main`** and **`/ (root)`**, then click **Save**.
4. Your website will be live at:
   👉 **`https://sumitgawai2326.github.io/portfolio-/`**
