System Architecture: AI-Based Smart Attendance System

Deep-dive technical workflow and computer vision pipeline
1

PWA Camera Stream Acquisition

The client-side React.js PWA requests HTTPS camera permissions and captures real-time video frames (30fps) with multi-student viewing angle normalization.

2

FastAPI REST & OpenCV Pipeline

Frames are sent asynchronously to FastAPI. OpenCV performs face bounding box localization and crops each detected face ROI.

3

SFace Deep Feature Extraction & Matching

SFace neural network generates 128-d feature embeddings. Cosine similarity compares the live vectors against registered student embeddings with strict threshold checks.

4

Verification, Anti-Duplicate & Ledger Recording

Unknown faces are rejected. Verified identities are checked against the current lecture session to prevent duplicate marking, then logged to the database ledger.

Frontend: React.js, Tailwind, PWA Service Workers
Backend: Python 3, FastAPI, Uvicorn
AI/CV: OpenCV, SFace Deep Neural Model
Hosting: Firebase Hosting (Frontend) + Render (Backend)
